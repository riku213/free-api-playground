無料APIお試しサイト

12の無料APIをボタン1つで試せるローカルサイトです。APIの呼び出しはサーバ側（Python標準ライブラリのみ）で行います。

P2P地震情報は実験的な扱いです。NASA APOD は DEMO_KEY で動いています（無料の個人キーへの置き換えを推奨します）。

OpenAlex 論文検索

論文をキーワードで検索します。

P2P地震情報（実験的）

最新の地震情報10件を表示します。実験的な扱いです。

Open-Meteo 天気

船橋市と東京都の現在の天気を表示します。

Open Library 本検索

本をキーワードで検索します。

NASA APOD 天文写真

NASAの今日の天文写真を表示します。DEMO_KEYで取得しています。

PokéAPI ポケモン

ポケモンの名前または図鑑番号で調べます。

Sumo API 力士

力士の一覧を表示します。

Cat Facts 猫の豆知識

猫に関する豆知識をランダムに表示します。

Dog API 犬の画像

犬の画像をランダムに表示します。

メトロポリタン美術館

「ひまわり」で検索した収蔵作品を表示します（画像のある作品を優先します）。

Open Trivia クイズ

5問の4択クイズに挑戦できます。選択肢をクリックして回答します。

DiceBear アバター

入力したシード（文字列）からアバター画像を作ります。

結果

ボタンを押すと、ここに結果が表示されます。
